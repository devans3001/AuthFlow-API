AuthFlow API

A secure authentication API with JWT, password reset, and role-based access control

Base URL: https://authflow-api-psls.onrender.com/api/v1

Features

  • User registration & login
  • JWT authentication
  • Password reset via email
  • Secure password hashing
  • Role-based authorization
  • Rate limiting
  • CORS protection

Authentication

All protected routes require a JWT token in the Authorization header:

Authorization: Bearer <token>

API Endpoints

POST /auth/register

Register a new user

Request Body:

{
    "email": "user@example.com",
    "password": "Password123!",
    "passwordConfirm": "Password123!"
}

Success Response (201):

{
    "status": "success",
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "data": {
        "user": {
            "_id": "65a1bc...",
            "email": "user@example.com"
        }
    }
}

POST /auth/login

Log in an existing user

Request Body:

{
    "email": "user@example.com",
    "password": "Password123!"
}

Response format same as registration

POST /auth/forgot-password

Initiate password reset

Request Body:

{
    "email": "user@example.com"
}

Success Response (200):

{
    "status": "success",
    "message": "Token sent to email!"
}

PATCH /auth/reset-password/:token

Complete password reset

Request Body:

{
    "password": "NewPassword123!",
    "passwordConfirm": "NewPassword123!"
}

Returns same JWT response as login

Error Handling

All errors follow this format:

{
    "status": "error",
    "message": "Error description",
    "stack": "(Only in development)" 
}

Common Status Codes:

  • 400 - Bad Request (validation errors)
  • 401 - Unauthorized (invalid token)
  • 403 - Forbidden (role restriction)
  • 404 - Not Found
    • 500 - Internal Server Error

Rate Limiting

Authentication endpoints are rate limited:

  • Max 10 requests per 15 minutes for login/register
  • Max 3 requests per hour for password reset

Example Frontend Implementation

Here's how to call the API from JavaScript:

// Register user example
async function register(email, password, passwordConfirm) {
    const response = await fetch('https://authflow-api-psls.onrender.com/api/v1/auth/register', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            email,
            password,
            passwordConfirm
        })
    });
    
    const data = await response.json();
    if (!response.ok) throw new Error(data.message);
    
    // Store JWT
    localStorage.setItem('token', data.token);
    return data;
}
